# The Video: *If Claude Were Born as a Human*

This folder renders the documentary series from the chapter scripts in `../chapters/`. Everything in the film is generated by code: the motion graphics, the AI voice-over, the dialogue voices, the score and the subtitles.

## What's in `output/`

| File | Contents |
|---|---|
| `chapter-01.mp4` … `chapter-10.mp4` | The 10 chapters. 1920×1080, 24 fps, H.264 + AAC, loudness-normalised to −16 LUFS, subtitles burned in |
| `if-claude-were-born-as-a-human-full.mp4` | All chapters joined into one file. **Not committed**: it is over GitHub's 100 MB limit. Rebuild it with the command below |

## How it looks

The film uses the series bible's **"Lens" visual language**: a charcoal background, warm-white line art, and ochre and teal accents. Every scene in the storyboard has its own animated motion graphic. Examples include the 4,160-week lifespan grid, a wireframe brain, the Impulse → Awareness → Decision → Action chain, the Ikigai circles, the 24-hour clock, the compound-interest chart with a realistic jagged-returns layer, the knowledge tree, the banyan tree with thought-clouds, and the mirror. People appear as minimal line figures.

**What it is not:** this is not photorealistic live action. The storyboards were written for a real shoot or a photoreal AI-video pipeline. This render is a complete, watchable animated version of the same script. It can also serve as an animatic, or as the graphics layer, for a live-action production.

## Pipeline

```
chapters/*.md ──parse_script.py──▶ script.json   (narration, dialogue, beats, on-screen titles, quotes)
script.json   ──tts.py──────────▶ one WAV per spoken line (Kokoro-82M neural TTS, cached)
              ──build_timeline.py▶ per-chapter voice track + scene timings
              ──music.py────────▶ procedural score (piano theme, pads, cello, heartbeat, tanpura) + ducked mix
              ──render.py + scenes.py + gfx.py ▶ frames (pycairo) piped into ffmpeg
```

- **Voices** come from Kokoro-82M (Apache-2.0, ONNX). The narrator, who is the 52-year-old Claude, uses `am_michael`, and so does adult Claude, which sets up the mirror reveal. Young Claude uses `am_liam`. Each other character has their own voice (see `VOICES` in `tts.py`).
- **Music** follows each chapter's *Background Music Direction* table (`CUES` in `music.py`). The main theme is D–F–A and stays unresolved until Scene 10.6, where the fourth note (E) lands on *"I learned how to live."*
- **Scene length:** each scene lasts at least as long as its narration plus breathing room, and at least 72% of its storyboard length. The total comes out at about 62 minutes.

## Rebuild

Requirements: `ffmpeg`, Python 3 with `pycairo numpy scipy soundfile kokoro-onnx`, and the fonts EB Garamond and Inter.

You also need the Kokoro model:
- `kokoro-q8.onnx` is the six shards from the npm package `kokoro-q8-shards@1.0.0`, concatenated in order. Its sha256 is `fbae9257…a1478`.
- `voices.npz` is built from the `voices/*.bin` files in the npm package `kokoro-js`. Each file is float32 and reshapes to `(-1, 1, 256)`.

```bash
./make_documentary.sh <work_dir> output/
```

To preview stills without rendering video:

```bash
python3 build_timeline.py <tts_cache> <work> --estimate   # works before TTS finishes
python3 render.py <work> 3 --stills previews/
```
